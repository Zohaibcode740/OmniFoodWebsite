# 🍽️ Omnifood — Healthy Meal Delivery Website

Omnifood is a modern, responsive food subscription landing page designed for a healthy meal delivery service. The website showcases personalized meal plans, pricing, customer testimonials, recipes, and a subscription call-to-action.

This project focuses on building a clean, responsive, and user-friendly website using **HTML and CSS**, with **Ionicons** for interface icons.

## 📸 Project Overview

Omnifood provides users with a simple way to discover a healthy meal subscription service. The website includes multiple sections designed to guide visitors from learning about the service to signing up.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/omnifood.git
```

### 2. Open the project

```bash
cd omnifood
```

### 3. Run the website

Since this is a static HTML/CSS project, no backend or package installation is required.

Simply open:

```text
index.html
```

in your browser.

For the best development experience, you can also use **VS Code with the Live Server extension**.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

Responsive behavior is handled through the `queries.css` stylesheet.
